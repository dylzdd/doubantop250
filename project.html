豆瓣图书 Top250 榜单数据分析

以一份被广泛引用的「经典书单」为观察对象，用最基础的统计与可视化方法， 还原 250 本书背后的结构特征：它们有多老、有多热、由谁出版，以及排名是否真的等于口碑。

项目类型描述性数据分析
数据规模250 条 · 10 个字段
技术路线Python / pandas / Matplotlib
分析深度常规统计，无建模

01项目背景与目标

先讲清楚"为什么要做"，再说明"做完要得到什么"。

项目背景

豆瓣图书 Top250 是中文互联网上流传最广的经典书单之一，长期被读者当作选书参考。 它的排序并非单纯的销量排行，而是综合用户评分、评价人数、收藏与评论等多重信号的长期沉淀， 因此常被默认等同于「好书的标准答案」。

但榜单只给出一个排名，不解释排名背后的构成：为什么有些书评分很高却排在中段？哪些出版社常年霸榜？ 榜单里的书究竟有多「老」？这些问题榜单本身没有回答，而它们恰好可以用最基础的数据分析方法还原出来。 本项目即以该榜单为唯一观察对象，完整走通一次数据分析流程。

项目目标

  1. 描述目标完整刻画榜单整体结构：评分分布、热度分布、出版年份跨度、价格区间、出版社集中度。
  2. 关联目标观察排名、评分、评价人数、价格、出版年份之间是否存在明显的同向或反向关系，仅做分组对比与相关性描述。
  3. 结论目标形成 3–5 条有数据支撑、经得起追问的结论，并转化为对普通读者的选书建议。
  4. 工程目标完成「采集 → 清洗 → EDA → 可视化 → 结论」完整链路，全部步骤以脚本留档，保证可复现。
定位说明：本项目是描述性分析，目的在于「把一份熟悉的榜单讲清楚」，而非追求复杂模型或预测能力。 因此刻意不使用聚类、回归等算法，把精力放在数据质量与结论的可靠性上。

03数据源详细说明

公开可访问的榜单页，字段齐全但偏静态，清洗阶段的主要工作集中在三个文本字段上。

来源项说明
来源平台豆瓣读书 · 图书 Top250 榜单页
页面性质公开榜单页，无需登录即可查看
数据规模10 个分页 × 25 条 = 250 条记录
采集方式Python requests 请求页面 + BeautifulSoup 解析 HTML 结构化字段
采集约束请求间隔 2–3 秒；仅抓取公开展示的书籍信息，不采集用户评论与个人数据
快照说明记录具体采集日期；榜单动态更新，结论对应某一时点快照

字段清单（10 个）

字段名含义原始类型清洗要点
rank榜单排名 1–250整数直接使用，作为唯一标识之一
book_name书名文本去除副标题噪声，统一全半角
author作者信息文本（混杂）拆分作者、译者、国籍标注
publisher出版社文本统一「出版社 / 出版公司」等后缀写法
publish_date出版日期文本（格式不一）拆分为年份与月份，统一为数值
price定价文本（含「元」）去单位转浮点数
rating豆瓣评分浮点数直接使用，范围 0–10
rating_count评价人数文本（含「人评价」）去后缀转整数
quote一句话简介 / 短评文本仅作辅助参考，不参与数值分析
url详情页链接文本用于溯源核对

已知数据问题

字段偏静态：只有评分均值与累计评价人数，缺少销量、评分分布、读者画像与评价时间序列， 这决定了本项目只能做横截面描述。
版本重复：经典著作常有不同译本、不同出版社同时上榜，需按「书名 + 作者」判断是否为同一作品， 并明确保留策略（保留排名最高版本）。
文本不规整：出版日期存在「2005-1-1」「2010年5月」等多种写法，价格带单位，评价人数带中文后缀， 这三项是清洗阶段的主要工作量。
价格不代表市场价：榜单价格反映的是该在榜版本的定价，不能视作该书的市场均价。

04本次项目要解决的分析问题

五个问题由简到难递进，共同指向一个主线：这份榜单的结构是什么样的。

Q1排名靠前的书，评分一定更高吗？

分析思路：将排名分五段（1–50、51–100 … 201–250），对比各段评分均值与区间，再画排名—评分散点图观察形态。

关注点：若二者并非严格同向，说明评价人数等指标在起实际作用，这本身就是一个值得说明的发现。

Q2高分书是否也高热度？口碑与热度是否一致？

分析思路：以评分中位数、评价人数中位数为界，把 250 本书划入四个象限，统计各象限数量并举例。

关注点：识别「小众高分」与「大众经典」两类书的数量比例与特征差异。

Q3榜单里的书有多「老」？出版年份如何分布？

分析思路：统计出版年份分布与各年代占比，观察峰值年份，对比「2000 年前出版」与「近十年出版」的比例。

关注点：判断榜单是否存在时间偏向，以及新书进入榜单的难度。

Q4哪些出版社在「霸榜」？集中度有多高？

分析思路：统计各出版社入榜数量并排序，计算 Top10 出版社的入榜占比（CR10），结合出版社类型观察差异。

关注点：集中度高低可反映榜单是「少数机构主导」还是「广泛分布」。

Q5价格与口碑有关系吗？贵的书更容易得高分吗？

分析思路：按价格区间分组，对比评分均值与评价人数均值，画价格—评分散点图观察趋势。

关注点：预期二者关系微弱。若确实无显著关系，这一「排除性发现」本身就是有价值的结论。

05项目局限性说明

主动写清边界，比夸大结论更能说明分析者的判断力。

01数据范围局限

样本仅 250 条，且是平台筛选后的结果，并非随机抽样。所有结论只描述「这份榜单内部的结构」，不能外推为所有好书或整个图书市场的规律。

02指标维度局限

缺少销量、评分分布、读者年龄与地域、评价时间序列，无法分析「口碑随时间的变化」「不同人群的偏好差异」，也无法做用户分群。

03榜单机制不可解释

排序规则未公开，是算法与编辑共同作用的结果。可描述表面关系，但不能断言排名形成机制，也不能把相关性解读为因果。

04清洗规则带主观性

版本重复、日期格式混杂需人为设定规则（如同书保留排名最高版本）。规则不同，结果随之变化，因此每条判断都需在报告中显式说明。

05方法深度局限

仅使用描述性统计与基础可视化，未做假设检验与建模，因此不提供统计显著性结论，也无法给出预测。这是项目定位所致。

06时效局限

榜单持续更新，本项目结论对应某一时点的数据快照。时间推移后排名与评价人数均会变化，结论需重新采集数据验证。
